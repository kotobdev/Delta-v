# Vox Audio Files

This directory contains new vox sound files ported from impstation PR 1448.

Files included:
- voxchitter1.ogg
- voxchitter2.ogg  
- voxcoo1.ogg
- voxcoo2.ogg
- voxcry.ogg
- voxhiss.ogg

Note: The gasp sounds were not included because Delta-v already has VoxGasp collection with existing files.
